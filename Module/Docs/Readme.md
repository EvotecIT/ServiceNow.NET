# ServiceNow.PowerShell Module
## Description
PowerShell cmdlets for working with ServiceNow.

## ServiceNow.PowerShell Cmdlets
### [Add-ServiceNowAttachment](Add-ServiceNowAttachment.md)
Uploads a file as an attachment to a ServiceNow record.

### [Get-ServiceNowRecord](Get-ServiceNowRecord.md)
Retrieves a single ServiceNow record by its identifier.

### [Get-ServiceNowRecordList](Get-ServiceNowRecordList.md)
Streams records from a ServiceNow table.

### [Get-ServiceNowReport](Get-ServiceNowReport.md)
Retrieves a ServiceNow report.

### [New-ServiceNowRecord](New-ServiceNowRecord.md)
Creates a new record in a ServiceNow table.

### [Remove-ServiceNowRecord](Remove-ServiceNowRecord.md)
Deletes a record from a ServiceNow table.

### [Set-ServiceNowRecord](Set-ServiceNowRecord.md)
Updates an existing ServiceNow record.
